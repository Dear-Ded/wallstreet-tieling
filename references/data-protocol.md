
## 统一输出格式（强制）

> ⚠️ 每个子skill的最终输出必须包含以下结构化字段。

```yaml
role: "张铁柱"           # 角色名（必填）
timestamp: "2026-06-08"  # 输出时间（必填）
summary: "一句话摘要"     # 50字内（必填）
sections:                # 章节列表（必填）
  - title: "企业基础信息"
    data: |
      | 项目 | 内容 | 来源 |
      |------|------|------|
    confidence: "high"   # high/medium/low/待核实
sources:                 # 来源清单（必填）
  - "企查查, 2026-06-08"
  - "国家企业信用信息公示系统, 2026-06-08"
warnings: []             # 数据警告（可选）
  - "[待核实] 该项仅有单一来源"
```

## 刘文华合并规则（强制）

1. 按 role 分组 → 去重（相同数据合并 sources 字段）
2. 数据冲突 → 标注 `[冲突: 来源A vs 来源B]`
3. 优先级: 官方 > 商业平台 > WebSearch > 模型知识 > 推论
4. 任何章节数据缺失 → 输出 `未获取。如需此维度请单独查询`（不得保留空模板）
5. 所有 warnings 汇总到报告末尾
