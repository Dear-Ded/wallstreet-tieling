# 人员深度穿透手册

> 借鉴"社工库"思路，但严格限定在合法公开信息范围内。所有查询均为银行信贷业务所需的合法尽调内容。不做隐私侵犯，不做非法查询，所用的全是公开可得的数据——只是别人没耐心拼，我们有。
>
> **合规红线**：不做身份证号/手机号/家庭住址等隐私查询；不做非公开征信查询；不定性结论（如"品格有问题"）；不给建议（如"此人不可信"）。

---

## 方法论：碎片拼图法

```
一个人的风险画像 ≠ 某个单独信息
                 = 任职记录 ∩ 诉讼记录 ∩ 媒体曝光 ∩ 关联企业 ∩ 制裁名单 ∩ 专业资质 ∩ ...
```

**核心思路**：把散布在不同公开数据源中的碎片信息拼接成一幅完整的个人风险画像。

## 一、必查十维度

### 维度 1：任职图谱 — 他在哪些公司有角色？

| 数据源 | 查询内容 | 查询方式 |
|--------|----------|----------|
| 企查查/天眼查 | 法定代表人/董监高/股东身份 | 按姓名搜索 |
| 启信宝 | 任职历史（含已卸任） | 个人主页查询 |
| 国家企业信用信息公示系统 | 工商登记的主要人员 | WebFetch |
| 上市公司公告 | 董监高简历、薪酬、持股变动 | 巨潮资讯/港交所披露易 |
| IPO 招股说明书 | 核心团队详细背景（最全） | 巨潮资讯/证监会 |

**信号识别**：
- 同时担任 10+ 家公司法人 → 可能是壳公司群
- 曾担任失信企业的法人/高管 → 职业风险信号
- IPO 招股书中个人简历与实际工商记录不符 → 造假信号

### 维度 2：司法关联 — 他打过什么官司？

| 数据源 | 查询内容 | 查询方式 |
|--------|----------|----------|
| 中国裁判文书网 | 民事/刑事/行政判决 | 按当事人姓名搜索 |
| 中国执行信息公开网 | 被执行人/失信被执行人 | 按姓名+身份证号部分 |
| 中国庭审公开网 | 庭审录像（可了解案情） | 按当事人姓名搜索 |
| 人民法院公告网 | 破产/清算/送达公告 | 按姓名搜索 |
| 各地仲裁委员会 | 商事仲裁裁决 | WebFetch |
| 信用中国 | 行政处罚记录 | 按姓名搜索 |

**信号识别**：
- 作为被告的民间借贷纠纷 → 资金链紧张信号
- 多次被列入失信被执行人 → 信用严重恶化
- 在判决书中被提及为"关联方"或"实际控制人" → 隐性关联

### 维度 4：媒体与社交足迹 — 他在公共空间说了什么？

| 数据源 | 查询内容 | 查询方式 |
|--------|----------|----------|
| 百度新闻/百度资讯 | 新闻提及 | WebSearch |
| 微信公众号 | 深度报道/人物专访 | WebSearch |
| 微博 | 个人言论/舆情 | WebSearch |
| 知乎 | 专业领域讨论/公司评价 | WebSearch |
| 天眼查/企查查新闻 | 关联企业新闻自动聚合 | 平台内查询 |
| 行业垂直媒体 | 行业会议发言/获奖 | WebSearch |

**信号识别**：
- 被媒体曝光的争议事件 → 声誉风险
- 频繁在社交媒体发表极端言论 → 合规风险
- 长期无任何公开信息 → 信息不对称风险

| 中国人事考试网 | 职业资格证书（建造师/CPA/律师等） | WebFetch |

### 维度 6：关联人员网络 — 谁在跟他一起玩？

| 关联类型 | 发现方式 | 数据源 |
|----------|----------|--------|
| 共同任职 | 查询两人同时在哪些公司任职 | 企查查/天眼查 |
| 校友关系 | 同一学校/院系/年级 | 学信网/公开简历 |
| 前同事关系 | 曾在同一公司共事 | 企查查任职历史 |
| 诉讼同案 | 判决书中同时出现 | 裁判文书网 |
| 共同投资 | 两人共同投资同一企业 | 企查查/天眼查股东信息 |
| 亲属关系 | IPO 招股书/上市公司公告中的亲属披露 | 巨潮资讯 |
| 地址关联 | 同一注册地址/通讯地址 | 企查查/天眼查 |

**信号识别**：
- 与失信被执行人有密切关联 → 风险传导
- 通过代持人（亲属/秘书/司机）实际控制企业 → 隐性实控

|----------|----------|--------|

### 维度 8：企业经营信号 — 他管理的公司怎么样？

> 通过他担任法代/高管的公司经营状况，反向评估个人。

| 信号 | 含义 | 数据源 |
|------|------|--------|
| 所管企业频繁变更法人 | 控制权不稳定 | 企查查变更记录 |
| 所管企业大量注销 | 可能清理历史遗留问题 | 企查查状态 |
| 所管企业列入经营异常 | 管理能力存疑 | 企查查/公示系统 |
| 所管企业社保人数为 0 | 可能是空壳 | 企查查年报 |
| 所管企业注册资本实缴为 0 | 资本实力薄弱 | 企查查年报 |

### 维度 9：行业口碑 — 同行怎么评价？

| 数据源 | 查询内容 |
|--------|----------|
| 脉脉（职场社交） | 前同事/下属的匿名评价 |
| 知乎（公司评价话题） | 员工/合作伙伴的真实反馈 |
| 黑猫投诉/12315 | 消费者投诉中提及的负责人 |

### 维度 10：变更轨迹 — 他最近在干什么？

| 变更类型 | 潜在信号 | 数据源 |
|----------|----------|--------|
| 密集卸任多家公司法人/高管 | 切割风险、准备跑路 | 企查查变更记录 |
| 频繁变更企业注册地址 | 经营不稳定 | 企查查变更记录 |
| 突然减持/退出重要企业 | 预判风险撤离 | 上市公司公告 |
| 大量新增对外投资 | 套取信贷资金 | 企查查投资信息 |

## 二、人员穿透 SOP

```
Step 1：身份锁定
  1. 确认姓名（含曾用名）、身份证号部分（如有）
  2. 比对多个数据源确认是同一人（同名同姓风险）
  3. 如存在多个同名，按年龄/地域/行业交叉验证

Step 2：任职图谱扫描（维度1+维度6）
  1. 企查查/天眼查按姓名搜索任职企业
  2. 勾选"含历史任职"，获取完整任职轨迹
  3. 标注每家企业状态（存续/注销/吊销/异常）
  4. 识别关联人员网络（共同任职者、潜在代持人）

Step 3：司法风险核查（维度2+维度3）
  1. 裁判文书网搜索（当事人+关联方）
  2. 执行信息网搜索（被执行人+失信）
  3. OpenSanctions/OFAC 制裁筛查
  4. 信用中国行政处罚查询

Step 4：资质核实（维度5）
  1. 获取公开简历中的学历/资质声明
  2. 在对应资质平台核实
  3. 标注不一致处

Step 5：媒体与舆情（维度4+维度9）
  1. 百度新闻搜索
  2. 微博/知乎/脉脉舆情扫描
  3. 行业专业媒体报道

Step 6：风险信号汇总（维度7+维度8+维度10）
  1. 资产线索
  2. 所管企业经营异常
  3. 近期变更轨迹异常

Step 7：综合风险画像
  1. 汇总十维度发现
  2. 按风险信号强弱排序
  3. 标注信号来源
  4. 不作定性结论，只摆事实现状
```

## 三、交叉验证矩阵

> 关键发现必须有多源交叉验证才可信。

| 发现 | 验证方式 | 最少源数 |
|------|----------|----------|
| 同一人担任 A 公司和 B 公司法人 | 企查查 + 天眼查 + 公示系统 | 2 |
| 某人是失信被执行人 | 执行信息公开网 + 企查查 + 天眼查 | 2 |
| 某人学历为 XX 大学 | IPO 招股书简历 + 学信网（如可查） | 2 |
| 某人与某人有关联 | 企查查共同任职 + 裁判文书共同当事人 | 2 |
| 某人曾有刑事犯罪 | 裁判文书网 + 新闻报道 | 2 |

## 五、对标"社工库"思路的合法升级

传统"社工库"的核心能力是"碎片拼接"——把散落在不同角落的公开信息手工拼成完整画像。我们做同样的事，但严格使用公开合法数据源：

| 传统社工库做法 | 我们的合法升级 | 数据源 |
|----------------|---------------|--------|
| 身份证号反查 | "姓名+公司+城市"反查 | 企查查/天眼查 |
| 手机号关联 | 企业注册联系电话反查 | 企查查工商信息 |
| 社交账号挖掘 | 公开新闻报道+社交媒体搜索 | WebSearch |
| 地址关联 | 同一注册地址的多家企业 | 企查查地址搜索 |
| 黑产数据 | 裁判文书+执行信息+行政处罚 | 官方公开数据 |

## 六、合规声明

> 所有查询均在银行信贷业务合法范围内，不涉及任何隐私侵犯。查询内容均为公开信息——我们只是系统化地收集和拼接，不做任何非法获取。
>
> 输出形式：只摆事实（"张XX担任15家企业法定代表人，其中3家状态为吊销"），不做评价（不说"此人是职业背锅侠"），不给建议（不说"建议关注此人"）。
