## 一、核心方法论：数字足迹拼图

```
一个自然人的数字足迹 = 身份信息（姓名/曾用名/身份证号/护照）
                    + 数字身份（用户名/邮箱/手机号/IM账号/数字钱包）
                    + 社交图谱（好友/粉丝/关注/群组/互动）
                    + 资产痕迹（域名/网站/APP/服务器/知识产权）
                    + 行为轨迹（发帖/签到/交易/登录/搜索）
                    + 关联网络（亲属/同事/同学/同IP/同设备/同地址）
```

### 维度 2：数字身份发现（借鉴 Maigret/Blackbird/Sherlock）

> **核心思路**：一个人在不同平台可能使用相同或相似的用户名/邮箱/手机号。利用这一点，可以跨平台追踪一个人的完整数字足迹。

| 方法 | 工具/方式 | 覆盖范围 |
|------|----------|----------|
| **用户名跨平台搜索** | Maigret (3100+站点)、Blackbird (600+)、Sherlock (300+) | 全球社交媒体/论坛/电商/代码平台 |
| **邮箱反查** | Holehe (100+站点)、Blackbird、Hunter.io | 注册了哪些网站 |
| **手机号反查** | PhoneInfoga、Truecaller API | 手机号归属地/运营商/关联账号 |
| **头像反向搜索** | Google Images、Baidu识图、Yandex Images、TinEye | 同一头像在哪些平台使用 |
| **用户名变体生成** | 自动生成常见变体（加数字/下划线/缩写） | 覆盖更多平台 |
| **昵称关联** | 同一昵称在不同平台的活跃度 | 微博/知乎/豆瓣/贴吧/小红书/抖音 |

**Maigret 核心能力（供参考）**：
```bash
# 搜索用户名在3000+站点的账号
maigret username --all-sites --pdf report.pdf
# 递归追踪（从A账号关联信息中发现B账号）
maigret username --recursive
# 导出结构化数据
maigret username --json report.json
```

**Blackbird 核心能力（供参考）**：
```bash
# 用户名搜索600+平台
blackbird -u username
# 邮箱反查
blackbird -e email@example.com
# AI分析+PDF报告
blackbird -u username --ai --pdf
```

## 六、自动化调查工作流（借鉴 SpiderFoot 模块化思路）

```
Step 1：种子信息收集
  ├── 姓名 + 身份证号(部分)
  ├── 手机号（如有）
  ├── 邮箱（如有）
  ├── 企业名称
  └── 社交账号（如有）

Step 2：身份扩展（Maigret风格）
  ├── 用户名 → 3000+平台搜索 → 发现关联账号画像
  ├── 邮箱 → Holehe反向 → 发现注册平台列表
  ├── 手机号 → PhoneInfoga → 归属地/运营商/关联
  └── 头像 → PimEyes/Google Images → 跨平台头像匹配

Step 3：深度画像（Maltego风格）
  ├── 工商信息 → 全部任职企业 + 股东关系
  ├── 司法记录 → 裁判文书 + 执行 + 失信
  ├── 制裁扫描 → OpenSanctions/OFAC/UN
  ├── 社交分析 → 全平台内容+时间线+互动网络
  ├── 域名资产 → WHOIS+子域名+ICP+历史快照
  └── 资质核实 → 学历/资格证/执业注册

Step 4：关联扩展（六度关联）
  ├── 亲属 → 上市公司公告/裁判文书/工商股东
  ├── 密切商业伙伴 → 共同任职≥3家企业
  ├── 代持嫌疑 → 老人/无业/偏远地区股东
  ├── 一致行动人 → 同一时间买卖同一股票
  └── 资金关联 → 裁判文书中提及的往来方

Step 5：交叉验证
  ├── 企查查 vs 天眼查 vs 启信宝（三源验证）
  ├── 公开简历 vs 工商登记（履历真实性）
  ├── 社交媒体 vs 官方公告（言行一致性）
  └── 自述学历 vs 学信网（学历真伪）

Step 6：输出报告
  ├── 综合风险评估表（信号汇总）
  ├── 关联网络图谱（主要关联方/关联企业）
  ├── 时间线（关键事件/变更节点）
  └── 证据链附录（每项发现的来源）
```

## 七、信号关联矩阵

> 多信号组合 → 加速风险识别

| 组合模式 | 信号组合 | 风险方向 |
|----------|----------|----------|
| **跑路组合** | 密集卸任+地址变更+减持退出+限制消费 | 可能准备跑路/切割责任 |
| **壳老板组合** | 10+企业法人+注册资本认缴0+社保0 | 职业壳公司操盘手 |
| **骗子组合** | 学历造假+资质造假+多起合同纠纷 | 诚信严重存疑 |
| **洗钱组合** | 频繁变更法人+大量壳公司+跨境交易 | 可能涉及洗钱 |
| **代持组合** | 老人/无业股东+实控人与表面股东无关联 | 股权代持 |
| **掏空组合** | 关联交易占比高+其他应收款激增+减持 | 可能转移资产 |
| **造假组合** | 应收异常+现金流背离+毛利率异常+审计频繁更换 | 财务真实性存疑 |
