## Tier 0：专业金融终端

> **接入方式**：这些终端通常需要本地安装客户端+机构授权，无法通过纯API直接调用。但我们可以通过以下方式间接利用：
> 1. 指导用户在终端中查询特定数据，将结果粘贴给我们分析
> 2. 如果用户本地有Python环境，调用终端SDK
> 3. 利用公开的终端数据源网站进行交叉验证

### Wind（万得）

| 属性 | 详情 |
|------|------|
| **全称** | Wind金融终端 / 万得终端 |
| **定位** | 中国最大的金融数据服务商 |
| **Python SDK** | `WindPy`（需本地Python+Wind客户端） |
| **安装** | `pip install wind-python-sdk`（需要Wind客户端授权） |
| **数据覆盖** | A股/港股/美股/债券/基金/期货/宏观/行业 |
| **核心优势** | 中国企业数据最全面、最深度的财务数据 |
| **适用场景** | 财务分析、行业对标、估值模型、宏观研究 |
| **间接接入** | 指导用户在Wind中导出Excel/CSV，我们读取分析 |
| **参考文档** | https://www.wind.com.cn/portal/zh/ClientApi/index.html |

**Wind Python SDK 核心用法（供参考）**：
```python
from WindPy import w
w.start()
# 获取财务报表
data = w.wsd("000001.SZ", "roe,roa,debttoassets", "2025-01-01", "2025-12-31")
# 获取行业数据
data = w.wss("000001.SZ,600036.SH", "pe_ttm,pb_lf,total_shares")
# 获取宏观数据
data = w.edb("M0000545, M0000546", "2025-01-01", "2025-12-31")
```

### Bloomberg（彭博）

| 属性 | 详情 |
|------|------|
| **全称** | Bloomberg Terminal / 彭博终端 |
| **定位** | 全球最大的金融数据终端 |
| **Python SDK** | `blpapi`（Bloomberg API） |
| **安装** | 需要彭博终端+DAPI授权 |
| **数据覆盖** | 全球股票/债券/外汇/商品/衍生品/宏观 |
| **核心优势** | 全球数据覆盖面最广、实时行情最快 |
| **适用场景** | 跨境企业分析、全球行业对标、外汇/大宗商品 |
| **间接接入** | 指导用户在彭博中运行 `BDP`/`BDS`/`BQL` 查询，导出结果 |
| **参考文档** | https://www.bloomberg.com/professional/support/api-library/ |

**彭博API 核心函数（供参考）**：
```
BDP (Bloomberg Data Point)    — 当前数据点查询
BDS (Bloomberg Data Set)      — 批量数据集查询
BQL  (Bloomberg Query Language)— 高级查询语言
BECS (Bloomberg Excel)        — 通过Excel间接获取
```

**AKShare 核心接口（供参考）**：
```python

df = ak.stock_zh_a_hist(symbol="000001", period="daily")

# 行业数据
df = ak.stock_board_industry_summary_ths()
```

## 🧊 冷门但可信的数据源（高价值隐藏信息）

> **核心原则**：以下数据源虽然不常被提起，但都是政府/机构官方运营，数据可信度高。往往能从这些"偏门"数据中发现常规尽调看不到的关键信号。

| **联合国安理会制裁名单** | 联合国制裁个人与实体 | 官网查询 | ⭐⭐⭐⭐⭐ |

## 数据源使用优先级

```
银行信贷尽调场景推荐顺序：

1. 企业基本信息 → 企查查/天眼查（最快、最全）
2. 财务深度分析 → Wind > AKShare（财报详细度逐层下降）
3. 行业对标分析 → Wind > 国家统计局 > World Bank
4. 全球企业分析 → Bloomberg > Refinitiv > Yahoo Finance
5. 宏观经济研判 → Wind > 国家统计局 > FRED > World Bank
6. 法律诉讼查询 → 企查查/天眼查 > 裁判文书网
7. 关联方识别 → 企查查/天眼查股权穿透 > OpenCorporates
8. 舆情监控 → 百度新闻 > 微博 > 微信公众号
```

## 接口扩展原则

> 周通执行以下原则：
> 1. **先免费后付费**：优先使用免费数据源
> 2. **先本地后远程**：优先使用本地可调用的API
> 3. **先精确后模糊**：优先使用结构化API，其次WebFetch抓取
> 4. **交叉验证**：关键数据点至少两个来源互相验证
> 5. **降级兜底**：主数据源不可用时自动切换到备用方案
