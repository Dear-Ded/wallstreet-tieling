# 数据源速查表

> 按优先级排列。实际可用源取决于当前环境。Tier 编号与 README 一致。

## Tier 0：专业金融终端（需授权）

| 数据源 | 查询内容 | 调用方式 |
|--------|---------|---------|
| Wind 万得 | A股/港股/债券/基金全面金融数据 | API（需授权，成本高） |
| Bloomberg | 全球市场数据/公司基本面 | 终端/API（需授权，成本高） |
| Refinitiv | 全球金融数据/公司分析 | API（需授权） |
| 东方财富 Choice | A股/行业/宏观数据 | 客户端/API |
| 同花顺 iFinD | A股/港股/产业数据 | 客户端/API |

## Tier 1：开箱即用（无需配置）

| 数据源 | 查询内容 | 调用方式 |
|--------|---------|---------|
| WebSearch | 工商信息/新闻/舆情/行业报告 | 搜索 `{关键词} site:gsxt.gov.cn` |
| WebFetch | 网页正文提取 | 指定URL直接提取 |
| 模型知识 | 行业常识/分析框架 | 内置于prompt |

## Tier 2：免费官方（直接访问）

| 数据源 | 查询内容 | URL |
|--------|---------|-----|
| 国家企业信用信息公示系统 | 工商/处罚/异常 | gsxt.gov.cn |
| 中国裁判文书网 | 诉讼案件 | wenshu.court.gov.cn |
| 中国执行信息公开网 | 被执行人/失信 | zxgk.court.gov.cn |
| 信用中国 | 行政处罚/信用 | creditchina.gov.cn |
| 公开招聘/公告/官网 | 任职与经营线索 | WebSearch |
| 公开招投标/政府采购 | 业务活动线索 | 官方网站 |

## Tier 3：MCP增强（推荐安装）

| 工具 | 功能 | 安装 |
|------|------|------|
| maigret | 3000+网站用户名搜索 | `pip install maigret` |
| sherlock | 400+网站用户名追踪 | `pip install sherlock-project` |
| theHarvester | 邮箱/子域/IP收集 | `pip install theHarvester` |

不可用时自动降级为WebSearch。初次检测到缺失时提示用户安装（默认选降级）。

## Tier 4：本地OSINT（开源情报）

| 平台 | 免费功能 | 付费功能 |
|------|---------|---------|
| 企查查/天眼查/启信宝 | 基础工商/股东/风险概览 | 深度股权穿透/关联网络 |
| AKShare/Tushare | A股数据API | — |

## Tier 5：商业免费层（部分免费）

Wind/Bloomberg/Reuters → 需要机构授权。如果用户环境已配置，优先使用。

---

**实际可用源通常在10-30个，取决于当前环境。**
