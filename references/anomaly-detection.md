# 企业反常行为识别手册

> 经商办企业过程中存在大量"操作手法"——有的游走灰色地带，有的直接违法违规。我们的任务不是做"法官"来判断对错，而是做"CT机"来扫描异常。每一个结论都必须有数据支撑，每一个推论都必须有证据链。
>
> **核心原则**：只摆信号，不跳结论。列出"观察到的事实模式"，让专业人员自己判断——但我们会把常见模式提前准备好。

## 第一章：推理严谨性铁律

### 严禁的推论方式

| ❌ 禁止 | ✅ 替代 |
|--------|--------|
| "该公司存在财务造假嫌疑" | "应收账款增速(45%)是营收增速(12%)的3.75倍，与同行业均值(1.1倍)偏离显著" |
| "实控人通过关联交易掏空公司" | "2025年向3家关联方销售占比62%，毛利率低于非关联销售15个百分点。3家关联方注册时间均在交易前3个月内，实缴资本均为0" |
| "这是壳公司" | "注册资本1000万(认缴0元)、社保人数0人、注册地址为集群注册、无有效专利商标、近3年无纳税记录" |
| "资金已被挪用" | "2025年经营现金流-2300万，其他应收款同比增加1800万，其中1200万为与关联方往来款，无对应商业合同" |

### 推论三步法

```
Step 1：事实陈述 → 原始数据，不加工
Step 2：数据对比 → 与行业均值/历史趋势/同规模企业对比
Step 3：偏离标注 → 偏离超过阈值的标注为[异常]，标注偏差幅度
```

## 第二章：财务类反常行为识别

### 一、收入造假信号

| 信号模式 | 观察指标 | 异常阈值 | 数据来源 |
|----------|----------|----------|----------|
| 纸面繁荣 | 应收账款增速 ÷ 营收增速 | > 2.0（正常≈1.0） | 资产负债表+利润表 |
| 现金流背离 | 经营现金流 ÷ 净利润 | < 0.3 持续2期 | 现金流量表+利润表 |
| 客户集中度高 | 前五大客户占比 | > 60% | 年报/招股书 |
| 客户异常 | 前五大客户成立不足1年 | 任一客户成立<1年 | 企查查/天眼查 |
| 毛利率异常 | 毛利率与行业均值偏差 | > 15个百分点 | 利润表+行业数据 |
| 销售激增 | 单一季度营收占全年 | > 50%且集中在年末 | 年报/季报 |
| 海外收入存疑 | 海外收入占比激增且无物流佐证 | 占比变化>20个百分点 | 年报+海关数据 |

### 二、资产质量恶化信号

| 信号模式 | 观察指标 | 异常阈值 | 说明 |
|----------|----------|----------|------|
| 其他应收款膨胀 | 其他应收款 ÷ 总资产 | > 10% | 常见资金占用渠道 |
| 商誉虚高 | 商誉 ÷ 净资产 | > 30% | 并购溢价风险 |
| 存货异常 | 存货周转天数同比增加 | > 50天 | 跌价风险 |
| 在建工程长期挂账 | 在建工程持续>3年未转固 | > 3年 | 延迟折旧虚增利润 |
| 研发支出资本化率 | 资本化率 | > 50% | 虚增利润 |
| 预付账款异常 | 预付账款同比增幅 | > 100%且无对应合同 | 资金占用信号 |

### 三、负债与偿债能力预警

| 信号模式 | 观察指标 | 异常阈值 |
|----------|----------|----------|
| 短债长用 | 短期借款 ÷ 总借款 > 80% 且长期资产占比高 | > 80% |
| 隐性负债 | (应付票据+其他应付款异常增长) ÷ 营收 | > 15% |
| 担保超额 | 对外担保总额 ÷ 净资产 | > 50% |
| 受限资产 | 受限资产 ÷ 总资产 | > 50% |
| 表外负债 | 未并表子公司负债（需穿透） | 任一子公司资产负债率>80% |

### 四、现金流异常

| 信号模式 | 观察指标 | 信号含义 |
|----------|----------|----------|
| 经营性现金流持续为负 | 连续3年，净利润为正 | 利润无现金支撑 |
| 筹资性现金流主导 | 连续2年经营现金流<0且筹资>0 | 靠借钱维持经营 |
| 投资性现金流异常 | 大额投资且无明确项目进展 | 资金去向不明 |

## 第三章：关联交易与利益输送识别

### 关联交易典型手法

| 手法 | 操作方式 | 识别信号 |
|------|----------|----------|
| 高价采购 | 以高于市场价向关联方采购 | 关联采购毛利率 < 非关联采购毛利率 |
| 低价销售 | 以低于市场价向关联方销售 | 关联销售毛利率显著低于非关联 |
| 资金占用 | 通过其他应收款向关联方提供资金 | 其他应收款款龄>1年，无对应商业合同 |
| 虚假贸易 | 无商业实质的购销交易 | 同一批货物在关联方间循环交易 |
| 代偿债务 | 为关联方债务提供担保后被动代偿 | 担保金额 > 净资产50%，被担保方经营异常 |
| 壳公司中转 | 通过表面非关联公司进行利益输送 | 注册时间短/无实缴/同地址/同电话/同法人 |

### 关联方识别清单

- [ ] 同一实际控制人名下企业
- [ ] 实际控制人亲属（配偶/子女/父母）名下企业
- [ ] 高管及其亲属名下企业
- [ ] 同一注册地址/联系电话
- [ ] 同一园区/同一代理记账公司
- [ ] 历史上存在过控制关系（已退出但仍实质上控制）
- [ ] 前员工创立的企业
- [ ] 主要客户/供应商的股东与公司人员重叠
- [ ] 工商变更记录中曾出现过的人员

## 第四章：壳公司与换壳操作识别

### "壳"的特征画像

| 维度 | 典型特征 |
|------|----------|
| 注册资本 | 认缴制下金额高但实缴为0 |
| 人员 | 社保参保人数0或极少（1-3人） |
| 地址 | 集群注册/工业园区虚拟地址/同一地址注册多家 |
| 资产 | 无固定资产/无知识产权/无土地房产 |
| 经营 | 无纳税记录/无招投标/无海关进出口 |
| 变更 | 成立时间短/频繁变更法人/频繁变更经营范围 |
| 联系方式 | 无固定电话/用虚拟号/多个公司共用 |
| 网站 | 无官方网站/ICP备案信息异常 |

### "换壳"识别信号

| 操作模式 | 识别信号 |
|----------|----------|
| 旧壳注销新壳注册 | 旧公司密集注销→同时新公司密集注册，人员/业务高度重叠 |
| 法人轮换 | 短期内多人轮流担任法人 |
| 地址迁移 | 频繁变更注册地址，尤其跨省迁移 |
| 股权代持 | 新增股东为老人(>65岁)/偏远地区/无商业背景 |
| 经营范围突变 | 短期内大幅变更经营范围 |

## 第五章：经营异常信号

### 非财务预警信号

| 维度 | 信号 | 含义 |
|------|------|------|
| 社保 | 参保人数骤降 | 裁员/经营萎缩 |
| 社保 | 社保欠缴 | 现金流紧张 |
| 纳税 | 纳税额骤降与营收增长背离 | 营收真实性存疑 |
| 水电 | 生产型企业用电量下降（如可获取） | 产能利用率下降 |
| 招投标 | 长期无中标 | 市场竞争力下降 |
| 海关 | 出口退税额骤降 | 出口业务萎缩 |
| 诉讼 | 劳动争议案件激增 | 劳资关系恶化 |
| 变更 | 高管频繁变动 | 管理层不稳定 |
| 变更 | 审计机构频繁更换 | 审计意见购买 |
| 年报 | 年报多次延期披露 | 财务整理困难 |
| 新闻 | 负面新闻/被监管问询 | 合规风险 |

## 第六章：行业特有"操作手法"

### 房地产/建筑工程业

| 手法 | 操作方式 | 识别信号 |
|------|----------|----------|
| 假按揭 | 以员工/亲属名义办理按揭套取银行资金 | 同一楼盘大量贷款人无购房需求 |
| 工程款虚增 | 虚报工程进度/虚增工程量 | 工程进度与付款金额不匹配 |
| 阴阳合同 | 备案合同与实际执行合同不一致 | 合同金额与市场价偏离 |
| 捂盘惜售 | 已竣工但长期不办理产权证 | 竣工与交付间隔异常长 |

### 贸易/批发业

| 手法 | 操作方式 | 识别信号 |
|------|----------|----------|
| 循环贸易 | A→B→C→A循环交易，虚增流水 | 同一批货物循环交易，单价异常 |
| 融资性贸易 | 以贸易名义提供融资（垫资） | 毛利率接近0，资金占用远超行业水平 |
| 刷单虚增 | 虚假交易刷流水 | 交易对手方为新注册壳公司 |
| 虚构出口 | 虚假出口报关骗取退税 | 出口金额与物流数据不符 |

### 制造业

| 手法 | 操作方式 | 识别信号 |
|------|----------|----------|
| 产能虚报 | 虚报产能获取更多信贷额度 | 用电量与产能不匹配 |
| 存货虚增 | 虚假存货盘点 | 存货周转天数远高于行业 |
| 成本转移 | 将费用资本化减少当期成本 | 在建工程/长期待摊费用持续增长 |
| 关联采购 | 高价从关联方采购原材料 | 原材料成本高于市场价 |

### 互联网/科技业

| 手法 | 操作方式 | 识别信号 |
|------|----------|----------|
| 刷量造假 | 刷DAU/MAU/GMV数据 | 用户ARPU值远低于行业 |
| 收入确认激进 | 总额法变净额法之间的切换 | 营收规模突变 |
| 研发资本化 | 大量研发支出资本化 | 资本化率>50% |
| 股权激励粉饰 | 以股权代替现金薪酬降低成本 | 管理费用率异常低 |

## 第七章：信号聚合与推断规则

### 单信号 vs 多信号

```
单信号 → 标注[注意]，不形成结论
双信号 → 标注[异常]，说明潜在风险方向
三信号及以上 → 标注[高危]，附带完整证据链
               但仍然不直接定性，让证据说话
```

### 信号组合加速识别

| 组合模式 | 信号组合 | 典型情景 |
|----------|----------|----------|
| 壳公司组合 | 认缴0+社保0+地址集群+无纳税 | 空壳公司 |
| 财务造假组合 | 应收异常+现金流背离+毛利率异常 | 收入虚增 |
| 资金占用组合 | 其他应收款高+关联交易占比高+经营现金流负 | 实控人挪用 |
| 换壳组合 | 密集注销+密集注册+人员重叠+地址迁移 | 换壳操作 |
| 跑路前兆组合 | 密集卸任+减持退出+频繁变更地址+诉讼激增 | 准备跑路 |

### 证据链标准

```
任何推论必须满足：
1. 原始数据可查 → 标注来源
2. 对比基准明确 → 行业均值/历史趋势/同规模企业
3. 偏离幅度量化 → 具体百分比/倍数
4. 替代解释已排除 → 标注"已排除季节性因素/一次性事件等"
```
