## 🎯 前后端任务看板交流方式

### 任务看板结构（本项目）
- **中央管理**：`<REPO_ROOT>`
  - `ROADMAP.md` — 整体进度看板
  - `PROJECT.md` — 项目入口与当前状态
  - `WORKFLOW.md` — 工作流程与规范
  - `sessions/` — 每轮对话工作日志
- **代码仓库**：`<REPO_ROOT>`（GitHub: Dear-Ded/wallstreet-tieling）
- **AI 接手顺序**：PROJECT.md → WORKFLOW.md → sessions/ 最新日志

### 任务分配与追踪
- **Phase 为单位的里程碑管理**（ROADMAP.md）
  - 每个 Phase 有明确的状态：✅ / ⏳ / 🔴
  - 每个事项有编号（如 P11-3）便于引用
- **提交信息规范**（conventional commits）
  - `feat:` 新功能 / `fix:` 修复 / `chore:` 杂项
  - 括号标注 Phase 编号（如 `fix(P11-3)`）
- **工作日志**（sessions/YYYY-MM-DD-work-log.md）
  - 记录当日完成事项、技术决策、提交记录
  - 下次对话 AI 读取最新日志即可接手

### 前后端协作（本项目的 Agent 架构）
- **Orchestrator**（蒋宗明）：中央调度，分发任务给各 Agent
- **13 个角色 Agent**：各自独立，通过 Orchestrator 协调
- **数据预抓取**：`data_fetcher.py` 根据 agent_id 返回对应数据
- **Function Calling**：Agent 需要外部数据时，通过 `_execute_tool()` 调用工具
