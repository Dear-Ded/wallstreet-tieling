## 🛡️ 防杜撰体系：六层纵深防御

本项目最强的工程资产——远超"请勿编造"的单行指令。

| 层级 | 机制 | 说明 |
|:-----|:-----|:-----|
| **第一层** | 🚫 绝对禁止 | "你绝对不能编造数据！没有查到就说没查到。" 作为每个系统提示的第一条注入 |
| **第二层** | 📎 来源绑定 | 所有数据必须可追溯到具体工具调用。5个MCP连接器：企查查(qcc-company)、天眼查(tyc-mcp/162工具)、灵犀金融搜索、NeoData、富途API |
| **第三层** | 🏷️ 来源标注格式 | `[来源: 天眼查, 搜索"华为技术有限公司", 2026-06-09]` — 含工具名、参数、时间戳 |
| **第四层** | ❓ 不确定度标记 | `[已确认]` 多源交叉验证 · `[单源]` 仅单一来源 · `[未获取]` 未查到 · `[数据不一致]` 多源冲突 · `[推算]` 基于可用数据估算 |
| **第五层** | 🔄 自校验循环 | 数据缺口协议: L1(直接MCP查询) → L2(间接推算/关联推断) → L3(标记缺失，不编造) |
| **第六层** | 📐 金融领域约束 | 财务期间标注（不得跨期混用）、法律风险分类、金额单位规范、禁止输出信贷决策结论 |

> 实现位置: [`api/wst.py`](api/wst.py) 第45-107行 `NO_FABRICATION_RULE` 常量（64行结构化防御指令）

## ✅ 质量保障体系：三道防线

### L1 快速扫描 — 正则引擎，零LLM成本

纯Python正则扫描，亚毫秒级反馈：

| 检查项 | 检测内容 | 正则规则数 |
|:-------|:---------|:----------|
| 信贷决策词 | 建议通过/不建议/建议/推荐/应授信/可放款/风险可控 + 15+变体 | 15+ |
| 模糊词 | 大概/可能/也许/似乎/差不多/左右/估计/应该/好像/或许 + 10+变体 | 20+ |
| 来源标注 | 超100字符输出必须含 `[来源:]` 标记 | 1 |
| 截断检测 | 输出<200字符标记为可疑 | 1 |

### L2 深度验证 — LLM评分 0-100

`validate_dd_output()` 五维加权评分：

| 维度 | 扣分规则 |
|:-----|:---------|
| 杜撰信号 | 数据与来源不符、凭空生成数字、模糊归因 → **-15分/项** |
| 来源覆盖率 | 关键字段未标注来源 → **-10分/项** |
| 模糊术语 | 使用"大概/可能/估计"等 → **-5分/词** |
| 数据缺口 | 应获取但标记[未获取] → **-5分/项** |
| 未标注数字 | 数值型数据无来源 → **-8分/项** |

### L3 政委重试引擎 — 人格化PUA执法

吴德厚政委三级递进反馈，最多3次重试，不阻塞流水线：

- **L1 技术纠偏**: "数据来源呢？把每个数字的来源标清楚。"
- **L2 同行施压**: "郑慎之交叉验证发现你3处数据不一致，其他同事都能做到，你怎么回事？"
- **L3 降级标记**: "已累计3次不合格，本报告标注为'政委降级——数据可靠性受限'，请用户注意。自动降级，不阻塞流程。"

### 跨智能体一致性校验（郑慎之）

自动化结构化字段提取 → 容忍度比对 → 冲突解决：

| 字段 | 容忍度 | 处理 |
|:-----|:------|:-----|
| 注册资本 | ±5% | 差异超5%标记冲突 |
| 成立日期 | 精确匹配 | 不一致标记P0错误 |
| 法定代表人 | 精确匹配 | 不一致标记P0错误 |
| 双源冲突 | — | 启动第三方多搜索引擎仲裁 |

> 实现位置: [`api/unified_supervisor.py`](api/unified_supervisor.py) — 1000行完整实现（L1扫描、L2评分、政委引擎、哨兵监控、交叉验证）

### 6条条件分支规则（Phase 2自动触发）

Phase 1完成后自动检测信号，动态追加Phase 2角色：

| 检测信号 | 追加角色 | 原因 |
|:---------|:--------|:-----|
| 实控人异常（代持/多层嵌套/境外架构） | 马力全 (反洗钱) | 排查名义股东、代持协议 |
| 大额存贷双高（存款+贷款均超净资产50%） | 赵刚 (风险官) | 深度现金流分析 |
| 大量关联方（>10家或交易额超营收30%） | 赵刚 (风险官) | 关联交易公允性尽调 |
| 现金流质量问题（经营现金流/净利润<0.5） | 郑慎之 (审计) | 收入确认粉饰检测 |
| 失信被执行人记录 | 张铁柱 (法律合规) | 司法风险深度挖掘 |
| 注册信息不一致（工商地址/法人/注册资本多个来源冲突） | 郑慎之 (审计) | 信息真实性验证 |

| LLM API Key | DeepSeek / OpenAI / MiMo 任一 | 粘贴模式仍可用（依赖宿主模型） |
