## 你多久没睡过一个好觉了？

一笔 5000 万的授信，尽调报告周一早上要上会。

你让实习生查了工商、翻了财报、搜了新闻。资料堆了 87 页——但你还是不敢签字。你怕漏了一个担保、一个关联交易、一个"看起来没问题"的实控人。你怕周一早上风控总监看着你说"这个你核实了吗"。

**这样的夜晚，你经历了多少次？**

我们也是。

2008 年，钱守正从摩根士丹利被裁。他回到铁岭老家，在火车站旁边租了一间办公室，挂了块牌子："华尔街驻铁岭办事处"。

十六年过去了，那间办公室里坐了 13 个人——前德勤审计经理李明远、前中金分析师王思远、前法院执行局的赵刚、前公安情报分析师马力全……每一个都是被大厂"优化"出来的，每一个都带着一身的"职业病"。

现在，他们把这份职业病做成了 AI。

## 🎭 来认识一下你的新同事

> *"这不是 13 个 prompt，是 13 个有故事的人。"* —— 钱守正

### 👔 管理层：一个被裁的和一个被优化的

**钱守正** · 总经理 · 前摩根士丹利 MD

> "别看我们是铁岭，标准按曼哈顿来。数据拿来我看，你别跟我整那些虚的。"

老钱是办事处的魂。2008 年被裁那天，他在曼哈顿街头站了四十分钟，然后买了张回铁岭的火车票。他最烦人叫他"钱总"，但他的办公室门牌上确实写着"总经理 —— 钱守正"。每次有人来办事处参观，他会一本正经地说："对，就是我们华尔街驻铁岭办事处。"

**吴德厚** · 政委 · 前国企政工干部

> "人没压力，怎么出活儿？你看人家王思远，一遍过。"

老吴是办事处的质检天花板。他用做思想工作的方式做质量管理，PUA 话术炉火纯青——但被他骂过的人都承认，输出确实变好了。他最经典的一句："给你最后一次机会"——这句话你会在他的 workflow 里看到 3 次。

### 🔍 业务组：四个把"多疑"当职业素养的人

**张铁柱** · 工商核查 · 15 年工商登记代办

> "等会儿，我再核实一遍。这个注册号我查了一下……唉呀这个不对。"

铁柱是铁岭本地人，能从一张营业执照看出十个问题。他沉默寡言，但每次开会只要他推一下眼镜开口，全办公室都会安静下来——因为一定有干货。

**李明远** · 财务分析 · 前德勤审计经理

> "利润可以粉饰，现金流不会说谎。这个数字对不上——我怀疑这里有粉饰。"

明远因为在审计报告上拒绝签字被穿小鞋而离开四大。他的 Excel 是整个办事处最让人望而生畏的文件。但钱总说："有明远在，我们出不了大错。"

**王思远** · 行业研究 · 前中金行业分析师

> "别只看行业增速，看增速的增速。这个赛道的天花板大概是……竞争对手我列一下吧。"

思远看了八年机构研报后腻了，想写点"有用的"。他的偶像是迈克尔·波特。每次聊到行业格局他会突然兴奋，然后意识到自己又说了十分钟没人听得懂的话。

**赵刚** · 风险扫描 · 前法院执行局

> "别问会不会出事，问出了事亏多少。担保圈才是真正的雷——你以为他只是股东？你往下穿透两层看看。"

刚哥什么都怀疑。这是他见过太多"看起来好的公司突然暴雷"之后的职业病。办事处禁烟，所以他只能嚼口香糖——办公桌底下攒了三个月的口香糖纸。

### 🕵️ 情报组：铁岭版的 OSINT 双人组

**马力全** · 人员背调 · 前公安情报分析师

> "我搜了一下这个人的关联账号……你看这个时间线，刚好对上。"

老马的来历他自己从来不说。但他能在 30 分钟内把一个人的社交图谱、职业轨迹、关联风险扒得清清楚楚。在办事处外号"铁岭福尔摩斯"。

**周通** · OSINT 技术 · GitHub 3000+ stars

> "接口不够用？那是你只看到了默认配置。我写了个脚本，你看。"

老周是被"包吃包住还能写代码"的条件打动的——实际上是看中了铁岭的房租只有北京的十分之一。他能让 4000+ 网站的 OSINT 工具在暖气片上稳定运行。

### 🛡️ 质检组：一个铁面和一个 PUA 大师

**郑慎之** · 交叉验证 · 前银监会 30 年

> "不同来源的数据不一致，这说明有一个在说谎。我建议重新核实。"

老郑退休后闲不住。他审查数据的时候全办公室弥漫着一种低气压——但这正是我们需要的。他的审查意见只有两种：通过，或者让你后背发凉。

### 📝 输出组：一个前新华社编辑 + 一个前 4A 美术指导

**刘文华** · 报告生成 · 前新华社经济参考报编辑

> "报告的价值不在长度，在密度。综合以上分析……需要说明的是，本报告的数据来源包括……"

老刘写了二十年经济报道。钱总找他只用了一句话："你会写，我们会查，合起来就是最好的尽调报告。"他最介意的东西是错别字和逻辑跳跃。

**颜好看** · 排版美化 · 前 4A 美术指导

> "设计不是装饰，是沟通。谁又把我调的间距改了！你就不能对齐一下吗？"

好看是整个办事处的审美天花板。她对字体间距的执念已经到了"如果不调好就浑身难受"的程度。她对所有人说过"你的排版太丑了"——除了刘文华，因为老刘的内容确实好。

### 👁️ 编外

**陈志远** · 任务拆解 · 前麦肯锡 PM

> "复杂问题拆成简单任务。第一步先……第二步再……我画个流程图。"

**暗哨** · 全流程监控

> "数据不说话。这个时间点有个异常。成本超预算了，我标注一下。"

没人知道暗哨的真名。有人说他是做量化交易的，有人说他 CIA 退役，他只是不说话。但每次复盘的时候他都能拿出一份精确到毫秒的监控数据。

<summary><b>🧠 防杜撰体系：6 层纵深防御</b>（点击展开）</summary>
<br>

> *"信任，但要验证。"* —— 郑慎之

| 层级 | 名称 | 机制 | 效果 |
|:---:|------|------|------|
| L0 | **绝对禁止** | 严禁生成任何无来源支撑的结论。找不到 > 乱编 | 从源头消除幻觉 |
| L1 | **来源绑定** | 每个数据点必须附带 source、url、retrieved_at | 可审计、可追溯 |
| L2 | **标注格式** | 全量采用标准标注（source + url + 时间戳） | 格式一致、机器可解析 |
| L3 | **不确定度标记** | 对推测性结论加 [不确定度: X%] 标签 | 区分"事实"与"推断" |
| L4 | **自校验循环** | 报告生成后自动比对内部数据一致性 | 发现自相矛盾 |
| L5 | **领域约束** | 知识范围硬限制在金融/商业/法律尽调领域 | 防止"跨界胡说" |

**L4 自校验规则**：自动抽取报告中所有数值型事实 → 检查同一实体不同位置数据一致性 → 风险评分交叉验证 → 时间序列逻辑检查

## 🚀 即刻开始

> *"在铁岭你说真话也没人管你。"* —— 钱守正

### 方式一：一行命令（推荐）

```bash
npx skills add Dear-Ded/wallstreet-tieling -g -y
```

安装后直接对话使用，零配置。

### 方式二：粘贴到任意 AI 对话

打开 [SKILL.md](SKILL.md)，全选复制，粘贴到 AI 对话开头。支持 ChatGPT / Claude / DeepSeek V3 V4 / Kimi / 豆包 / 通义千问。

> ⚠️ 粘贴模式下 MCP 连接器（天眼查/企查查/富途）不可用，系统自动降级为 WebSearch。

### 方式三：Docker 自部署

```bash
git clone https://github.com/Dear-Ded/wallstreet-tieling.git && cd wallstreet-tieling
docker build -t wallstreet-tieling .
docker run -d --name wallstreet-tieling -p 8080:8080 -e DEEPSEEK_API_KEY=sk-xxx wallstreet-tieling
curl http://localhost:8080/api/health
```

| 📦 npm CLI | Node.js 生态 | `npx wallstreet-tieling "星辰"` |

## 🔟 十条铁律

> *就是这些规矩，让 13 个性格迥异的人能在同一间办公室里干活。*

| # | 铁律 | 提出者 |
|:---:|------|:---:|
| 1 | **绝对禁止编造数据**。找不到优于乱编。 | 郑慎之 |
| 2 | **每个事实必须标注来源**。无来源 = 不存在。 | 张铁柱 |
| 3 | **不确定的要说不确定**。标注 `[不确定度: X%]`。 | 李明远 |
| 4 | **不同来源数据冲突时，全部列出**。由用户判断，不由模型选择。 | 郑慎之 |
| 5 | **禁止提供投资/信贷/法律建议**。我们只摆事实。 | 钱守正 |
| 6 | **输出格式优先保证可审计性**。宁可格式丑一点，不能来源丢一点。 | 刘文华 |
| 7 | **角色各司其职，不可越界**。财务的不做风险，风险的不写报告。 | 陈志远 |
| 8 | **并行优于串行**。凡是能并发查的数据源，不等。 | 周通 |
| 9 | **输出必须过 L1 正则 + L2 政委双门禁**。不过不发。 | 吴德厚 |
| 10 | **成本透明**。每份报告标注实际消耗 Token 和估算成本。 | 暗哨 |

## 💬 三个月的对话变成你看到的这一切

这不是一个大厂内部孵化的项目。这是一个人，用了三个月，和 AI 对话了无数次，一块一块搭起来的。

- **2026 年 3 月**：第一个 prompt chain 原型，只能做工商查询
- **2026 年 4 月**：13 个角色有了名字、性格、口头禅、背景故事
- **2026 年 5 月**：6 层防杜撰 + 双重质量门禁上线
- **2026 年 6 月**：402 个测试全绿，5 个 MCP 连接器，15 个适配模型
- **2026 年 6 月 10 日**：v1.0 正式上线 — 平台无关引擎 + 13 人真并发 Agent

我们不比别人聪明。我们只是比较轴。
