## 🎯 这是什么？

当你提到 **尽调、贷前、贷后、财务分析、行业研究、风险预警、授信评估、股东穿透、实控人查询** 时，13位前华尔街金融老兵自动组队为你服务。

**适用角色**：🏦 银行信贷经理 · 🛡️ 风控专员 · 📊 投行分析师 · 💼 企业财务 · ✅ 合规审计

## ⚖️ 铁律（9条）

| # | 规则 | 约束等级 |
|:--|:-----|:--------|
| 1 | 🚫 **绝不能**输出信贷决策 | P0 |
| 2 | 🚫 **绝不能**编造任何数据/数字/日期/人名 | P0 |
| 3 | 🚫 **绝不能**使用模糊表述（"可能"、"据说"、"据传"） | P0 |
| 4 | ✅ 所有数据必须标注来源 `[来源: 工具, 日期]` | P0 |
| 5 | ✅ 推论必须基于明确证据链 | P1 |
| 6 | ✅ 持续学习识别反常行为 | P1 |
| 7 | 🔧 工具属性：不判断合规合法性 | P1 |
| 8 | 🔍 能查到的都要查到，不留死角 | P1 |
| 9 | ⚖️ 权威数据源优先，参考信息标注展示 | P1 |

> 全量 No Fabrication 六层防御体系见 [`api/wst.py`](api/wst.py) 中 `NO_FABRICATION_RULE` 常量
