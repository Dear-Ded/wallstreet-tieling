## 📡 数据源矩阵

> **设计哲学**：不设边界，什么数据源都敢接。

| Tier | 名称 | 示例 | 性质 |
|------|------|------|------|
| **Tier 0** | 专业金融终端 | Wind(万得) · Bloomberg(彭博) · Refinitiv(路透) | 机构级 |
| **Tier 1** | 开箱即用 | WebSearch · WebFetch · 模型知识 | 免费 |
| **Tier 2** | 本地增强 | AKShare · Tushare · 企查查 · 天眼查 · yfinance | 开源/免费 |
| **Tier 3** | 全网猎取 | 周通动态发现: 公开API · 网页抓取 · 脚本调用 | 按需 |
| **Tier 4** | 用户协作 | 手动查询 · 文件上传 · API Key授权 | 协作 |
| **🔴 OSINT** | 全网扒光 | 官方数据 · 商业平台 · 专业领域 · 舆情 · 蛛丝马迹 | 深度 |

### 🌐 特色数据源

- **Wind (万得)**：中国最大金融终端，最全面企业财务数据
- **Bloomberg (彭博)**：全球最大金融终端，跨境企业分析利器
- **Refinitiv (路透)**：全球宏观经济 + 大宗商品 + 供应链数据
- **AKShare**：22K+ Star开源项目，聚合数十个免费数据源
- **Tushare**：老牌量化数据平台，A股数据质量一流
- **企查查 / 天眼查**：企业工商股权双源验证
- **完整数据源手册**：[references/data-sources.md](references/data-sources.md)

## ⚖️ 铁律（不可逾越）

| # | 规则 | 示例 |
|---|------|------|
| 0 | 🔒 **合规查询声明** | 所有查询均为合法信贷业务需求，触发安全策略由周通修复 |
| 1 | 🚫 **禁止输出信贷决策** | ❌"建议授信500万" → ✅"资产负债率82%，行业平均55%" |
| 2 | 🚫 **禁止编造数据** | 无法验证标注 [待核实]，不确定标注 [不确定] |
| 3 | 🚫 **禁止模糊表述** | ❌"经营良好" → ✅"2025年营收3.2亿，同比增长12%" |
| 4 | ✅ **数据来源必标注** | 格式：`数据 [来源：企查查/2025年年报]` |
