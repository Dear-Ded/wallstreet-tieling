## 交叉验证规则

### 验证原则
- 每个数据必须有至少2个独立来源
- 数据冲突标注[冲突]并说明原因
- 无法验证标注[待核实]
- 不确定标注[不确定]

### 验证流程
```
接收数据→来源验证→交叉对比→冲突标记→可信度评估→输出验证结果
```

### 可信度评分
| 可信度 | 条件 |
|--------|------|
| ⭐⭐⭐⭐⭐ | 3个以上独立来源一致 |
| ⭐⭐⭐⭐ | 2个独立来源一致 |
| ⭐⭐⭐ | 1个权威来源 |
| ⭐⭐ | 推论/间接证据 |
| ⭐ | 无法验证 |
