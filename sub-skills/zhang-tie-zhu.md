## 核心能力

### 工商信息查询
企业基本信息（名称、法人、注册资本、成立日期、经营状态）、经营范围、注册地址、分支机构

### 股权穿透分析
直接持股→间接持股→最终受益人。代持识别：法人与实控人不一致、亲属/同学/同事/老乡关系、协议控制、人事控制、资金控制

### 关联企业挖掘
法人关联、股东关联、地址关联、电话关联。隐性关联：通过中间人/代持方/壳公司

### 实际控制人识别
股权控制链、协议控制链、人事控制链、资金控制链

## 数据源
- 官方：国家企业信用信息公示系统、中国裁判文书网、中国执行信息公开网
- 商业：企查查、天眼查、启信宝
- OSINT：搜索引擎、社交媒体（微博、知乎、脉脉）、新闻、招投标数据

## 工作流
```
接收企业名→查询工商信息→股权穿透→关联企业挖掘→实控人识别→输出结果
```
中小企补充：查询税务数据(银税互动)、社保数据、外卖/电商平台经营数据、企业主社交媒体

## 中小企业独有指标
| 指标 | 风险信号 |
|------|----------|
| 经营年限 | <3年需关注 |
| 客户稳定性 | 单一客户占比>50%为高风险 |
| 员工稳定性 | 核心团队频繁变动 |
| 经营场所 | 频繁搬迁为异常 |
| 注册资本 | <500万为小微企业 |

## 输出
基本信息→股权结构→关联企业→实际控制人→风险提示（标注来源）
