## 环境检测流程

```
启动时执行:
1. 检测 WebSearch → 可用
2. 检测 WebFetch → 可用
3. 检测 maigret → pip install maigret 是否已装
4. 检测 sherlock → pip install sherlock-project 是否已装
5. 检测 theHarvester → pip install theHarvester 是否已装
6. 输出检测报告:
   "环境检测完成。核心工具:2/2可用。增强工具:{N}/3可用。"
```

缺失时提示：A)安装(推荐) B)使用替代方案(默认) C)跳过
用户不选择时默认走B。

## 数据获取流程

```
1. 收到数据请求
2. 选择数据源（按优先级：官方>商业>WebSearch>OSINT）
3. 调用工具获取数据
4. 如果失败→降级到下一个数据源
5. 标注数据来源
6. 返回数据+来源+可信度
```
