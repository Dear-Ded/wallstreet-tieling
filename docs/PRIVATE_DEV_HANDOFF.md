# Public-Safe Handoff Notice

This public repository intentionally does not include private development
handoff details.

Private operational notes, local machine paths, dirty-worktree checkpoints,
implementation-agent instructions, credentials, browser profiles, cookies,
runtime logs, and unpublished repository coordination must stay outside the
public release package.

Use the public release and project documents instead:

- `docs/RELEASE_PORTAL.md`
- `PROJECT_TASKBOARD.md`
- `docs/API_CONTRACTS.md`
- `docs/DESKTOP_AGENT_HOSTS.md`
- `release/variants.yaml`

Before publishing or mirroring this repository, run the release hygiene and
secret-scan checks and confirm that no local runtime artifacts are staged.
